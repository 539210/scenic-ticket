# 景点售票系统稳定化最终报告

报告日期：2026-07-14

状态：M11 文档校准与最终自动化/真实数据库回归已完成；真实 Swing 手工清单尚未由桌面执行者签字，因此本报告在该项完成前不作为“全部 28 项已完成”的声明。

## 1. 项目目标与技术栈

项目将课程原始工程完善为可稳定演示的 Java Swing 景点售票系统，保留 Java 21、Swing、Maven、JDBC、MySQL、MongoDB、HikariCP、JUnit 5、SLF4J/Logback 和 BCrypt，并保留课程要求的五张原表及四个 MongoDB 集合。

## 2. 主要功能

- 用户注册、登录、退出、档案和基于 actor 回查的权限控制。
- 分类树、景点、UTF-8 详情、图片与 JSON 扩展属性维护。
- 多票种、未来游玩日期、每日 available/reserved/sold 库存。
- 待支付、主动支付、取消、过期、退款、部分/全部核销状态机。
- 已支付资格评论、每用户每景点唯一修改、完整字段展示。
- 个性化/热门/高分推荐、月报、热门排行、用户报告和综合统计。
- 用户/类型/级别/日期/关键词/条数组合审计及汇总、趋势。
- 管理员用户查询、详情、启禁和角色维护，保护自身和最后管理员。

## 3. 已知四问题修复

| 问题 | 根因 | 处理与证据 |
| --- | --- | --- |
| 评论显示错误 | 历史中文已损坏成问号，且旧渲染字段不全 | 独立评论 DTO/页签、UTF-8、混合 ID、脱敏/标签/双时间；不可逆内容显示明确降级提示 |
| 景点简介错误 | 历史正文损坏及异步选择残留 | 独立简介页签、选择代次保护、结构化编辑和数值/字符串 ID 兼容 |
| 图片只能看到地址 | 简介把 MongoDB `images` 数组格式化成 URL 文字 | 后台异步下载第一张有效图片、等比缩放后直接显示；无图、失效或非图片响应时完全隐藏图片区 |
| 推荐分不显示 | UI 与推荐结果未统一展示 | 固定推荐分列、0–100 格式和推荐理由，普通查询显示“-” |
| 审计条件查询异常 | 条件模型不完整且页面结果路由混乱 | `AuditLogQuery` 完整组合、四结果页、日期全天与清空/刷新回归 |

详细复现和根因见 `docs/KNOWN_BUG_REPRODUCTION.md`。

## 4. 其他关键缺陷处理

- 关闭服务层管理员权限绕过和任意订单状态改写两个 P0。
- 关闭待支付缺失、无日期库存、无退款、无核销、跨库审计误报、测试库不隔离和 Mongo 初始化破坏性风险等七个 P1。
- 修复评论重复、字段缺失、热门排行只显示 ID、数据库对象无调用、旧异步请求覆盖、订单按钮误导、空筛选 NPE、点击后选择漂移、价格估算显示旧值等 P2/P3。
- `AppFrame` 从页面巨石拆到 788 行，仅负责窗口/服务装配和对话框编排。

## 5. 数据库与迁移

MySQL 全新安装包含 10 表、12 外键、2 视图、2 存储过程、2 触发器。课程五表/字段保留，新增迁移记录、票种、每日库存、退款和核销表。Day08 旧结构升级实测保留历史用户、档案和订单。

MongoDB 保留 `action_logs`、`comments`、`item_details`、`system_logs`，增加兼容 ID 迁移、唯一/复合/文本索引。初始化脚本遇到既有受管集合会拒绝破坏性执行。

详细正向迁移、兼容和回滚见 `docs/DATABASE_MIGRATIONS.md`，结构见 `docs/MySQL_ER图.md` 与 `docs/MongoDB集合设计文档.md`。

## 6. 一致性和降级策略

- MySQL 核心订单/库存操作使用单连接显式事务与行锁。
- Mongo 审计失败不回滚已提交核心事实，UI 明确提示业务成功但审计失败。
- 新景点 Mongo 详情失败时尝试自动下架 MySQL 景点，避免无详情继续售卖。
- 跨库读取缺失时返回明确空状态/降级内容，不伪造 Mongo 与 MySQL 的原子事务。
