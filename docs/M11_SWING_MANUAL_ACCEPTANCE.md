更新时间：2026-07-14

本清单只记录真实可见桌面操作。自动测试或静态检查不能代替勾选；执行者应填写日期、结果和异常截图路径。

## 1. 隔离环境准备

1. 先完成 `docs/M10_REAL_DATABASE_ACCEPTANCE.md` 的 MySQL 全新测试库初始化。
2. 保持 MySQL80、MongoDB 服务运行。
3. 在新的 PowerShell 窗口设置仅对当前进程生效的测试库覆盖：

```powershell
$env:SCENIC_TICKET_MYSQL_URL='jdbc:mysql://localhost:3306/scenic_ticket_test?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true'
$env:SCENIC_TICKET_MONGODB_DATABASE='scenic_ticket_test'
.\start-app.cmd
```

MySQL 用户名/密码仍从本机未提交的 `db.properties` 读取。不得把密码写入本清单或截图。

## 2. 启动与认证

- [ ] `start-app.cmd --check` 显示 JDK 21 与 Maven 检查通过。
- [ ] 启动后只显示登录页，窗口标题为“景点售票系统”，没有空白页或遮挡。
- [ ] 空用户名、错误密码均显示中文提示，密码框会清空。
- [ ] 点击“注册新账号”进入独立注册页；“返回登录”可返回。
- [ ] 注册唯一测试账号，非法邮箱/手机号先被拒绝，合法输入后注册成功并返回登录。
- [ ] 新账号登录后只显示首页、个人档案、景点浏览、我的订单、统计报表。
- [ ] 右上角退出后返回登录页；重新登录不残留上一个账号的表格选择或状态消息。

## 3. 普通用户完整流程

- [ ] 首页正确显示当前用户名和“普通用户”，四个快捷入口均可导航。
- [ ] 个人档案保存真实姓名、证件号、地址和简介；刷新、退出重登后内容一致。
- [ ] 景点浏览不填条件可查询；关键词、预设关键词和景点类型组合筛选正常。
- [ ] 查询无结果时显示明确空状态，不保留上一次景点详情。
- [ ] 推荐菜单的“为你推荐/热门/高分”均返回表格；推荐分显示 0–100 或普通查询的“-”，选中后显示推荐理由。
- [ ] 选中景点后“景点概览/景点简介/游客评论”互不混杂；中文、图片、metadata、脱敏用户、评分、标签和双时间均可读。
- [ ] “可售票种与日期”拒绝过去日期和反向范围，合法范围显示票种、日期、原价、优惠、折后价、可售库存。
- [ ] “购买门票”只提供有库存组合；快速双击确认不会创建两张重复订单。
- [ ] 弹窗金额明确标为下单前估算；成功页展示服务端订单号、票种、日期、数量和实际金额。
- [ ] 新订单状态为待支付；选中后只启用“确认支付”和“取消待支付订单”。
- [ ] 确认支付后状态为已支付；刷新和重登后状态与金额快照不变。
- [ ] 对另一个待支付订单执行取消，库存恢复且按钮全部禁用。
- [ ] 对未来、已支付、未核销订单申请模拟退款，填写原因后订单取消；再次退款不可用。
- [ ] 对已支付未退款景点发表评论；再次提交修改原评论而不是新增第二条。
- [ ] 月度订单、热门排行和我的报告均为中文表格；热门排行显示景点名称而非仅 ID。

## 4. 管理员完整流程

使用初始化账号 `kongsc` 登录；密码见 README，不在截图中展示。

- [ ] 管理员可见后台管理和系统审计；首页快捷入口可达。
- [ ] 景点管理可查询上下架景点，选择后正确回填名称、分类、原价、优惠、状态和完整详情。
- [ ] 新增临时分类并设置上级；自身父级和循环层级被拒绝。
- [ ] 新增临时景点并维护 UTF-8 简介、两行图片、JSON metadata、价格与优惠；上下架后用户侧可见性正确。
- [ ] 新增/更新临时票种，设置今天与未来日期总库存；总库存小于已预留+已售时被拒绝。
- [ ] 用户管理按用户名/邮箱/角色/状态组合查询；详情包含档案、订单和行为概况。
- [ ] 管理员不能禁用自己、修改自己的角色，也不能降级/禁用最后一个有效管理员。
- [ ] “我的订单”可查询其他用户订单，但不会启用支付、取消或退款按钮。
- [ ] “门票核销”拒绝未来日期、非已支付、超数量订单；当天订单可部分核销并显示记录。
- [ ] 完成剩余数量后订单变为已完成；已核销订单不能退款。
- [ ] 月报、热门排行、指定用户报告和综合汇总均可刷新，刷新后保持当前结果页。
- [ ] 系统审计可组合用户、类型、级别、日期、关键词、条数；清空条件后重新查询。
- [ ] 审计汇总、趋势、用户操作均显示中文列；刷新当前结果不切错页且滚动位置可接受。

## 5. 交互、布局与并发感知

- [ ] 1280×720、1920×1080 及 Windows 125% 缩放下无关键按钮永久遮挡；页面可滚动。
- [ ] 连续快速点击查询/刷新时，最终只显示最新条件对应结果，不被旧请求覆盖。
- [ ] 后台任务期间忙碌遮罩可见并阻止重复鼠标/键盘提交，任务结束后恢复。
- [ ] 表格切换选择后，简介/评论异步结果不会写到新选择景点。
- [ ] 点击订单操作后立即切换行，实际操作仍对应点击时订单号快照。
- [ ] 所有错误显示中文业务提示或数据库/权限分类提示，没有直接把堆栈显示给用户。

## 6. 安全故障注入（不停止服务）

分别在新的 PowerShell 窗口执行；关闭该窗口即可清除覆盖。

### MongoDB 不可达

```powershell
$env:SCENIC_TICKET_MYSQL_URL='jdbc:mysql://localhost:3306/scenic_ticket_test?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true'
$env:SCENIC_TICKET_MONGODB_URI='mongodb://localhost:27018/?serverSelectionTimeoutMS=1500'
$env:SCENIC_TICKET_MONGODB_DATABASE='scenic_ticket_test'
.\start-app.cmd
```

- [ ] MySQL 注册/登录、支付或管理员变更成功时不被伪报为整体失败，并明确显示审计写入失败/扩展数据不可用。
- [ ] Mongo 详情、评论、统计不可用时界面可恢复，不冻结 EDT。

### MySQL 不可达

```powershell
$env:SCENIC_TICKET_MYSQL_URL='jdbc:mysql://localhost:3307/scenic_ticket_test?connectTimeout=1500&socketTimeout=1500'
$env:SCENIC_TICKET_MONGODB_DATABASE='scenic_ticket_test'
.\start-app.cmd
```

- [ ] 登录/查询显示数据库连接类中文错误，窗口保持可操作且可正常退出。
- [ ] 恢复正常覆盖并重启后可以重新登录，之前已提交的数据仍一致。
