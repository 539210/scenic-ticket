| 场景 | 当前覆盖 | 后续动作 |

## 手工 Swing 验收说明

当前环境没有自动点击 Swing 的工具链，且课程 DOCX 渲染依赖缺失。不会把静态检查或单元测试写成“手工通过”。M10/M11 将生成普通用户和管理员两套逐步冒烟清单，由可实际看到桌面的执行者完成并记录。
