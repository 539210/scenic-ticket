# 数据库快捷启动方案

## 本机服务名

系统兼容 MySQL 8.0+ 与 MongoDB 5.0+。下表版本和服务名仅记录本次开发机的已验证环境，不是运行时硬编码要求；其他机器可通过脚本参数指定服务名和端口。

当前检测到的 Windows 服务：

| 数据库 | 服务名 | 端口 |
| --- | --- | --- |
| MySQL 8.0.45 | `MySQL80` | `3306` |
| MongoDB 8.3.2 | `MongoDB` | `27017` |

这两个服务当前都是 `Automatic`，正常情况下开机后会自动启动。

## 只启动数据库

已新增脚本：

```text
start-databases.cmd
scripts/start-databases.ps1
scripts/start-databases.cmd
```

推荐在项目根目录运行：

```powershell
.\start-databases.cmd
```

也可以直接双击项目根目录的 `start-databases.cmd`。

如果当前终端已经在 `scripts` 目录，例如：

```text
<PROJECT_ROOT>\scripts>
```

则运行：

```powershell
.\start-databases.cmd
```

不要在 `scripts` 目录里执行 `scripts\start-databases.cmd`，那会变成查找 `scripts\scripts\start-databases.cmd`，PowerShell 还可能把 `scripts\...` 当成模块名解析。

如果数据库服务处于停止状态，Windows 可能要求管理员权限。此时右键 `scripts/start-databases.cmd`，选择“以管理员身份运行”。

注意：数据库启动脚本只会启动 MySQL 和 MongoDB，不会弹出系统图形界面。

## 启动 Swing 图形界面

如果数据库已经启动，在项目根目录运行：

```powershell
.\start-app.cmd
```

如果希望一键检查数据库并启动 Swing 图形界面，在项目根目录运行：

```powershell
.\start-system.cmd
```

`start-system.cmd` 会先检查 MySQL/MongoDB，再运行 `com.scenicticket.Main` 打开 Swing 主窗口。

## PowerShell 直接启动

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-databases.ps1
```

自定义服务名或端口示例：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-databases.ps1 `
  -MySqlService MySQL80 -MongoService MongoDB -MySqlPort 3306 -MongoPort 27017
```

脚本会做三件事：

1. 检查 `MySQL80` 服务状态，未启动则尝试启动。
2. 检查 `MongoDB` 服务状态，未启动则尝试启动。
3. 等待 `3306` 和 `27017` 端口可连接。

## 数据库初始化

第一次使用或重建数据库后，再执行初始化脚本：

```powershell
mysql -uroot -p < src\main\resources\sql\mysql_schema.sql
mysql -uroot -p < src\main\resources\sql\mysql_init_data.sql
mysql -uroot -p < src\main\resources\sql\mysql_views.sql
mysql -uroot -p < src\main\resources\sql\mysql_procedures.sql
mysql -uroot -p < src\main\resources\sql\mysql_triggers.sql
mysql -uroot -p < src\main\resources\sql\mysql_day07_optimization.sql
mongosh "mongodb://localhost:27017/scenic_ticket" --file src\main\resources\sql\mongodb_init.js
mongosh "mongodb://localhost:27017/scenic_ticket" --file src\main\resources\sql\mongodb_day07_optimization.js
```

Mongo 脚本使用连接 URI 当前数据库并校验允许名单，不会在文件内自动切库。初始化只需要执行一次；平时开发只需要运行快捷启动脚本。
