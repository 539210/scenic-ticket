# 景点售票系统用户使用手册

## 1. 系统说明

景点售票系统用于完成景点浏览、购票下单、评论互动、个性化推荐、统计报表和后台管理等操作。

系统分为两类账号：

| 账号类型 | 可使用功能 |
| --- | --- |
| 普通用户 | 注册、登录、维护个人档案、浏览景点、查看景点详情、查看评论、创建订单、发表评论、查看自己的订单、在景点浏览页查看推荐和统计 |
| 管理员 | 拥有普通用户功能，并额外拥有后台管理、订单状态管理、系统审计、系统汇总报表等功能 |

普通用户登录后看不到管理员专用页面和按钮；管理员登录后可以看到完整功能。

## 2. 启动系统

在项目根目录双击或运行：

```powershell
.\start-system.cmd
```

如果数据库已经启动，只需要打开 Swing 前端，可以运行：

```powershell
.\start-app.cmd
```

启动成功后，会先进入登录页面。登录成功后才会进入系统主界面。

## 4. 登录与注册

### 4.1 登录

1. 打开系统后进入登录页面。
2. 输入用户名和密码。
3. 点击“登录”。
4. 登录成功后进入系统首页。

如果用户名或密码错误，系统会用中文提示错误原因。

### 4.2 注册新账号

1. 在登录页面点击“注册新账号”。
2. 填写用户名、密码、邮箱、手机号。
3. 点击“注册”。
4. 注册成功后，系统会返回登录页面。
5. 使用新账号登录系统。

注册时需要注意：

- 用户名不能为空。
- 密码长度不能少于 6 位。
- 邮箱格式要正确。
- 手机号必须是 11 位大陆手机号。
- 如果输入不合法，系统会用中文提示具体哪里不合法。

## 5. 普通用户操作说明

### 5.1 首页

首页用于查看当前登录账号和账号类型。

普通用户首页会显示常用入口：

- 个人档案
- 浏览景点
- 查看订单
- 统计报表

管理员首页会额外显示：

- 后台管理
- 系统审计

### 5.2 个人档案

个人档案用于维护个人资料。

可填写内容：

- 真实姓名
- 证件号
- 地址
- 备注

普通用户使用时，用户ID可以不填，系统默认保存到当前登录账号。

填写完成后点击“保存档案”。保存成功后，底部状态栏会显示保存结果。

### 5.3 景点浏览

景点浏览是普通用户最常用的页面。

页面分为两块：

- 景点查询
- 购票与评论

#### 查询景点

可以使用以下方式查询：

| 操作 | 说明 |
| --- | --- |
| 查询全部 | 不填任何条件，列出系统中的景点 |
| 关键词查询 | 输入景点名称中的关键词，例如“南山” |
| 类型查询 | 选择自然景观、历史文化、主题乐园等类型，只查看该类型景点 |
| 为你推荐 | 根据当前账号的浏览、评论、下单等行为推荐景点 |
| 热门 | 查看近期热门景点 |
| 高分 | 查看评分较高的景点 |
| 清空条件 | 清空当前查询条件和结果 |

查询和推荐结果会显示在同一张表格中。点击表格中的一行，就会自动选中该景点。

推荐结果中的“推荐分”为统一的 0-100 分，保留 1 位小数；分数越高，表示系统越推荐。

#### 查看景点详情

1. 先查询景点。
2. 点击表格中的某个景点。
3. 点击“查看详情”。
4. 下方“景点详情与评论”区域会显示景点说明、开放时间、地址、评分和评论摘要。

如果没有选中表格，也可以手动填写景点ID后查看。

#### 查看评论

评论查看入口在“景点浏览”页面。

操作步骤：

1. 先查询景点。
2. 点击表格中的某个景点。
3. 点击“查看评论”。
4. 下方区域会显示该景点的评分概览和评论列表。

“查看详情”也会显示评论，但如果只想看评论，直接点击“查看评论”更清楚。

#### 购买门票

1. 查询并选中景点。
2. 在“购买票数”中填写要购买的门票数量。
3. 选择付款方式：微信、支付宝、银行卡或现金。
3. 点击“创建订单”。
4. 系统会按管理员设置的固定票价和折扣自动计算金额。
5. 当前版本为模拟付款，不连接真实支付平台；点击后会直接付款成功并生成订单。

用户不能自己填写订单金额。

票数必须是 1 到 99 之间的整数。

#### 发表评论

1. 查询并选中景点。
2. 先购买该景点门票并完成模拟付款。
3. 在“详情页评论（购买后可评论）”区域填写评分和评论内容。
4. 点击“发表评论”。

发表评论时需要注意：

- 未购买该景点不能评论。
- 评分必须是 1 到 5 之间的整数。
- 评论内容不能为空。
- 如果输入不合法，系统会用中文说明具体问题。

### 5.4 我的订单

普通用户点击“查我的订单”即可查看自己的订单。

订单表格会显示：

- 订单ID
- 用户ID
- 景点ID
- 金额
- 状态
- 创建时间

普通用户只能查看自己的订单，不能操作管理员专用的订单状态按钮。

### 5.5 统计报表

普通用户可以查看：

- 月度订单
- 热门排行
- 我的报告

“我的报告”会汇总当前账号的浏览、下单、评论等行为数据。

普通用户看不到系统审计汇总和后台仪表盘。

## 6. 管理员操作说明

管理员登录后会看到普通用户页面，以及额外的后台页面。

### 6.1 后台管理

后台管理包含两块：

- 分类管理
- 景点管理

#### 分类管理

可执行操作：

| 操作 | 说明 |
| --- | --- |
| 刷新分类 | 查看当前所有景点分类 |
| 新增分类 | 填写分类名和可选父ID，创建新分类 |

父ID可以不填。不填时表示创建顶级分类。

#### 景点管理

可执行操作：

| 操作 | 说明 |
| --- | --- |
| 新增景点 | 填写景点标题、预设类型、描述、票价和折扣后创建景点 |
| 更新状态 | 填写景点ID，选择上架或下架 |
| 修改价格折扣 | 填写景点ID、票价和折扣后更新景点售票规则 |

新增景点后，用户可以在“景点浏览”页面查询到该景点。

折扣使用百分比填写，`0` 表示不打折，`20` 表示打八折。

### 6.2 我的订单中的管理员操作

管理员进入“我的订单”页面后，可以：

- 按用户ID查询订单。
- 选中订单后更新订单状态。

订单状态包括：

- 待支付
- 已支付
- 已取消
- 已完成

### 6.3 统计报表中的管理员操作

管理员可以查看：

- 月度订单
- 热门排行
- 用户报告
- 仪表盘汇总

管理员可以填写用户ID查看指定用户报告；不填时默认查看当前管理员账号的数据。

“仪表盘汇总”包含热门景点、行为类型、热门标签、系统审计和月度订单等综合信息。

### 6.4 系统审计

系统审计用于查看系统日志和操作统计。

可执行操作：

| 操作 | 说明 |
| --- | --- |
| 查询日志 | 按用户ID、类型、级别查询系统日志 |
| 审计汇总 | 查看系统操作数量、告警数量、错误数量等汇总 |
| 审计趋势 | 查看每日系统操作趋势 |
| 用户操作汇总 | 按用户统计操作次数和异常情况 |

系统审计结果已经转换为中文说明，不会直接显示大段 JSON。

## 7. 页面滚动说明

系统页面内容较多时，可以使用鼠标滚轮或滚动条向下查看。

如果窗口较小，建议最大化窗口使用，表格和详情区域会更容易查看。

## 8. 常见问题

### 8.1 为什么登录后看不到后台管理？

只有管理员账号才能看到后台管理和系统审计。

普通用户登录后只显示用户侧功能，这是正常设计。

### 8.2 评论在哪里查看？

进入“景点浏览”页面，查询并选中景点后点击“查看评论”。

评论也会出现在“查看详情”的“景点详情与评论”区域。

### 8.3 查询景点一定要填分类ID吗？

不需要。

现在不需要记分类ID。可以直接选择“预设关键词”或“景点类型”，也可以点击“查询全部”。

### 8.4 创建订单时必须手动输入景点ID吗？

不需要。

先查询景点，然后点击表格中的某一行，系统会自动选中景点。之后可以直接创建订单或发表评论。

### 8.5 为什么不能自己填写金额？

景点票价和折扣由管理员维护，用户购买时只能填写票数和付款方式。

系统会自动计算实付金额，防止用户自行定价。

### 8.6 输入错误怎么办？

系统会在底部状态栏或当前页面给出中文提示。

常见错误包括：

- 手机号位数不正确。
- 邮箱格式不正确。
- 景点ID不是数字。
- 票数不是有效整数。
- 票价或折扣不是有效数字。
- 评论内容为空。
- 评分不在 1 到 5 之间。

按照提示修改后重新操作即可。

## 9. 退出系统

点击右上角“退出登录”即可退出当前账号并返回登录页面。

退出后需要重新输入账号密码才能再次进入系统。
